This is a programmer's assitance tool, useful for timing and counting. It provides a time and date clock, a lap timer, an interval timer, a mouse jiggler and an event counter.
Click on each control to start it, click again to stop it, and double-click to reset it. Stopped controls are invisible unless the mouse is over the dialog. 
On start the app moves itself to the top-right of the main display. It is intended for displays with solide black desktops.
